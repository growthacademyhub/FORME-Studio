2. Implemented GA4 & Meta DataLayer Events

view_item_list

Fires on PLP load or when filter changes. Maps to Meta ViewCategory.

select_item

Fires when user clicks a product card to open PDP.

view_item

Fires when product details page is loaded. Maps to Meta ViewContent.

add_to_cart

Fires after size/color validation succeeds. Maps to Meta AddToCart.

view_cart

Fires when user opens bag drawer or cart view.

begin_checkout

Fires when user proceeds to checkout. Maps to Meta InitiateCheckout.

add_shipping_info

Fires when shipping address & method are submitted.

add_payment_info

Fires when demo card choice is chosen. Maps to Meta AddPaymentInfo.

purchase

Fires upon successful demo order placement. Unique transaction_id prevents duplicate conversion counts on refreshes!

3. Recommended GTM Trigger & Tag Config

  1. Create a Custom Event trigger in GTM matching event name: add_to_cart|purchase|view_item|begin_checkout.
  2. For GA4: Create GA4 Event Tags referencing {{Event}} and pass Send Ecommerce Data checked.
  3. For Meta Pixel: Use Tag Assistant or GTM Meta Template to map value, currency, and content_ids.
